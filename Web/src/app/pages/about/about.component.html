About this project

Battlezone 98 Redux Game Watcher

An unofficial community utility for seeing current Battlezone 98 Redux multiplayer activity, understanding a lobby before joining, and finding useful game information in one place. It is not operated by Rebellion.

Privacy by design

What Game Watcher deliberately does not publish

Network addresses

The upstream lobby protocol can contain player IP, WAN, and LAN addresses. Game Watcher's public API uses a separate response model that omits those fields.

Writable web chat

The website can display a bounded recent window from selected public waiting rooms, but browser clients have no lobby-server credentials or operation for sending messages into Battlezone.

Player-level history

Historical activity stores aggregate counts only. It does not retain player names, player IDs, Steam IDs, chat text, lobby names/settings, or network identifiers.

Persistent chat archives

Observed chat is bounded in memory and is not persisted. It exists to show recent public waiting-room activity, not to build a permanent chat log.

What you are seeing

Data sources

Live multiplayer state
Public lobby/user/game metadata reported by the Battlezone 98 Redux multiplayer service. This remains the authoritative source for whether a lobby currently exists.
Steam
Public Steam profile/avatar information and public Workshop item metadata are used as optional enrichment. If Steam is unavailable, the lobby still renders.
Map catalog
Public BZ98R map metadata from gamelistassets.iondriver.com is used to resolve friendly map titles, previews, player ranges, and actual multiplayer modes. Raw lobby map filenames remain visible when a map cannot be resolved.
Unit database
Stock object-definition data is bundled with the site. Where a Battlezone Wiki craft render is available, the image is shown with a link back to its source.
Retention and local storage

How long information sticks around

Recent chat Bounded in server memory; not persisted.
Activity history Aggregate samples every five minutes by default, retained for up to 30 days.
Free Render deployment Activity history is non-durable and can reset on restart, spin-down, or redeploy.
Your browser The selected display time zone is saved locally on your device. The installable PWA also caches the application shell, never /api/ live data.
Open source

Inspect how it works

The watcher, public API boundary, read-only chat observer, activity aggregation, and web client are open source. That makes the privacy behavior and protocol assumptions reviewable.
